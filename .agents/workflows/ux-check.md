# UX Review & Interaction Checklist (`ux-check`)

本工作流程（Workflow）用於在功能變更、版本發布或介面優化時，全面檢驗 **Kanban App** 的使用者體驗 (UX)、互動流暢度、可存取性 (a11y) 與例外處理。

---

## 🎯 執行時機

* 新增或調整前端元件（如新增標籤篩選、修改卡片樣式、調整表單欄位）後。
* 執行 GitHub Pages 發布與正式上線前。
* 進行定期的可用性與介面走查（Usability Walkthrough）。

---

## 📋 檢查清單 (Inspection Steps)

### 第一階段：佈局與視覺層次 (Layout & Visual Hierarchy)

- [ ] **桌機端排版**：
  - 三欄（待處理、進行中、已完成）水平等寬併排，間距適中。
  - 欄位標頭指示燈（藍、黃、綠）與計數徽章（Badge）數值清晰且對齊。
  - 當卡片數量過多時，各欄位獨立滾動，不影響整頁佈局。
- [ ] **行動端響應式 (Mobile Responsive)**：
  - 螢幕寬度小於 900px 時，自動切換為流動單欄垂直排列。
  - 觸控目標（按鈕、卡片）尺寸符合人體工學（最小點擊範圍不小於 44x44px）。
- [ ] **色彩對比與無障礙**：
  - 深色背景 (`#0f172a`) 與主要文字 (`#f8fafc`) 符合 WCAG AA 對比標準（對比度大於 4.5:1）。
  - 優先級標籤（高/中/低）文字與背景顏色辨識度良好。

---

### 第二階段：拖曳放置體驗 (Drag & Drop Interactions)

- [ ] **拖曳起手視覺反饋**：
  - 抓住卡片開始拖曳時，原卡片透明度降為 45%、產生 2 度傾斜，鼠標指標變更為 `grabbing`。
- [ ] **目標放置區高亮**：
  - 卡片懸停於任何欄位上方時，該欄位應立即顯現品牌色虛線邊框（`.drag-over`），提示使用者可安全放下。
- [ ] **放置與狀態同步**：
  - 放開卡片時，卡片無縫落入目標欄位，對應的數量徽章立即同步更新數值。
- [ ] **邊界例外處理**：
  - 若將卡片拖出看板範圍或在無效區域釋放，卡片應優雅復原，不產生殘留陰影或資料損壞。

---

### 第三階段：表單與卡片互動 (Form & Card Usability)

- [ ] **彈窗焦點控制 (Focus Management)**：
  - 點擊「新增任務」時，彈窗淡入開啟，焦點自動定位於「任務名稱」輸入框，便於立即打字。
- [ ] **鍵盤快捷鍵體驗**：
  - 按下 `Esc` 鍵可立即關閉開啟中的彈窗。
  - 在輸入框按下 `Enter` 可直接觸發「儲存任務」提交。
- [ ] **表單驗證提示**：
  - 若未填寫任務名稱即點擊儲存，瀏覽器應跳出必填欄位提示，不允許建立空白卡片。
- [ ] **卡片操作顯隱性 (Affordance)**：
  - 滑鼠懸停於卡片時，右上角的「✎ 編輯」與「✕ 刪除」按鈕清晰顯現。
  - 點擊編輯可將原有內容回填至表單中供修改。
  - 點擊刪除具備確認防誤觸對話框（`confirm`）。

---

### 第四階段：持久化與空狀態 (Persistence & Empty States)

- [ ] **LocalStorage 自動同步**：
  - 任意新增、編輯、拖曳移動或刪除後，立即在瀏覽器中按下 `Cmd + R`（重新整理）。
  - 畫面應完全還原最後操作的卡片排列順序與內容。
- [ ] **空狀態提示 (Empty State)**：
  - 當某一欄位無任何卡片時，應顯示「尚無卡片，拖曳或點擊下方新增」的引導文字，避免留白引發疑惑。
- [ ] **批次清除體驗**：
  - 點擊「清除已完成」時，提示清除的卡片數量；若無已完成卡片則跳出友善提示，不執行多餘操作。
